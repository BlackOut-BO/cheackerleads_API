# Инструкция по оплате Abstract API

## Текущая ситуация

Из логов видно, что у вас закончилась квота на **Email Reputation API**:
- Ошибка: `"You have reached your quota. Please, subscribe to a paid plan to continue using this API."`
- Это означает, что бесплатный лимит исчерпан

## Как проверить тарифы и оплатить

### Шаг 1: Войдите в аккаунт Abstract API

1. Перейдите на https://app.abstractapi.com/
2. Войдите в свой аккаунт

### Шаг 2: Перейдите на страницу Email Reputation API

1. В Dashboard найдите **"Email Reputation API"** или перейдите по прямой ссылке:
   - https://app.abstractapi.com/api/email-reputation
2. На странице API будет раздел **"Pricing"** или **"Plans"**

### Шаг 3: Выберите план

Обычно Abstract API предлагает следующие планы:

#### **Free Plan (Бесплатный)**
- Обычно: **100 запросов/месяц**
- Подходит для тестирования
- **$0/месяц**

#### **Starter Plan (Стартовый)**
- Обычно: **1,000-5,000 запросов/месяц**
- Подходит для небольших проектов
- **Примерно $9-19/месяц**

#### **Professional Plan (Профессиональный)**
- Обычно: **10,000-50,000 запросов/месяц**
- Подходит для средних проектов
- **Примерно $49-99/месяц**

#### **Business Plan (Бизнес)**
- Обычно: **100,000+ запросов/месяц**
- Подходит для крупных проектов
- **Примерно $199+/месяц**

### Шаг 4: Оплата

1. На странице плана нажмите **"Subscribe"** или **"Upgrade"**
2. Выберите способ оплаты:
   - Кредитная/дебетовая карта (Visa, MasterCard, American Express)
   - PayPal (если доступно)
3. Введите данные для оплаты
4. Подтвердите подписку

## Расчет необходимого плана

### Ваш текущий объем

Из логов видно, что вы проверяете **78+ лидов** за раз. Если каждый лид содержит email, это:
- **78+ запросов** за одну проверку
- При проверке 10 файлов в месяц: **780+ запросов/месяц**
- При проверке 50 файлов в месяц: **3,900+ запросов/месяц**

### Рекомендации

- **Для тестирования**: Free Plan (100 запросов/месяц) - **бесплатно**
- **Для небольшого использования**: Starter Plan (1,000-5,000 запросов) - **$9-19/месяц**
- **Для регулярного использования**: Professional Plan (10,000+ запросов) - **$49-99/месяц**

## Альтернативные варианты

Если тарифы Abstract API слишком дорогие, можно рассмотреть альтернативы:

### 1. **Hunter.io Email Verifier**
- URL: https://hunter.io/
- Тарифы: от $49/месяц за 1,000 проверок
- Хорошая точность

### 2. **ZeroBounce**
- URL: https://www.zerobounce.net/
- Тарифы: от $15/месяц за 2,000 проверок
- Профессиональный сервис

### 3. **EmailListVerify**
- URL: https://emaillistverify.com/
- Тарифы: от $0.0025 за проверку
- Pay-as-you-go модель

### 4. **Clearout**
- URL: https://clearout.io/
- Тарифы: от $19/месяц за 1,000 проверок
- Хорошее соотношение цена/качество

## Важно

⚠️ **Перед оплатой проверьте:**
1. Точные тарифы на официальном сайте (они могут меняться)
2. Лимиты запросов в секунду (rate limiting)
3. Возможность отмены подписки
4. Наличие пробного периода

## После оплаты

После подписки на платный план:
1. Квота будет автоматически увеличена
2. API ключ останется тем же
3. Ошибки "quota_reached" должны исчезнуть
4. Проверки будут работать нормально
