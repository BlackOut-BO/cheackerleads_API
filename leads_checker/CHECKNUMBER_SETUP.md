# Настройка CheckNumber.ai для проверки WhatsApp

## 📋 Что нужно сделать

### 1. Получить API ключ CheckNumber.ai

1. Зарегистрируйтесь на [CheckNumber.ai](https://checknumber.ai/)
2. Перейдите в раздел **API Keys** или **Dashboard**
3. Создайте новый API ключ
4. Скопируйте ключ

### 2. Настроить API ключ в боте

Добавьте в файл `.env`:
```env
CHECKNUMBER_API_KEY=ваш_api_ключ_здесь
```

### 3. Проверить работу

После настройки бот будет использовать только CheckNumber.ai для проверки WhatsApp.

## 💰 Стоимость и тарифы

### Как работает CheckNumber.ai:

**Real-time API** (`/v1/whatsapp`) - который мы используем:
- ✅ **Платный** - каждый успешный запрос списывается с баланса
- ✅ **Мгновенный ответ** - результат приходит сразу
- ✅ **Учитывается в статистике** - все запросы видны в панели

**Bulk API** (`/v1/tasks`) - для массовой проверки через файлы:
- ✅ **Платный** - списывается с баланса
- ⏱️ **Асинхронный** - нужно создавать задачу и проверять статус
- ✅ **Учитывается в статистике**

### Сколько стоит:

Точные цены смотрите на сайте [CheckNumber.ai](https://checknumber.ai/pricing):
- Обычно от **$0.001-0.01** за проверку одного номера
- Есть разные тарифные планы с разными ценами
- Могут быть бесплатные кредиты при регистрации

### Почему может работать бесплатно:

1. **Бесплатные кредиты** - при регистрации могут дать тестовые кредиты
2. **Тестовый период** - может быть пробный период
3. **Баланс на счету** - если вы пополнили баланс, запросы списываются с него

## ✅ Проверка что все работает

### В логах бота вы должны видеть:

```
CheckNumber.ai success from https://api.checknumber.ai/v1/whatsapp (POST, auth: X-API-Key): +1234567890 -> valid=True (exists=True) | TransactionID: abc123xyz | Pricing: PAY
```

**Важно:**
- `TransactionID` - уникальный ID транзакции (можно проверить в панели)
- `Pricing: PAY` - означает что запрос платный и учитывается
- `Pricing: FREE` - означает что запрос бесплатный (тестовый)

### В панели CheckNumber.ai:

1. Перейдите в раздел **Transactions** или **Usage**
2. Найдите транзакции по `TransactionID` из логов
3. Проверьте баланс - если он уменьшается, значит все работает правильно

## 🔍 Как проверить что проверка реальная

### Признаки правильной работы:

1. ✅ API возвращает `'status': 'OK'` и `'pricingStrategy': 'PAY'`
2. ✅ В ответе есть `transactionId` - уникальный ID транзакции
3. ✅ В панели CheckNumber.ai видны транзакции с этими ID
4. ✅ Баланс уменьшается при каждом запросе
5. ✅ Результаты проверки различаются для разных номеров (не все "yes" или "no")

### Если в панели не видно запросов:

1. **Проверьте API ключ** - убедитесь что используете правильный ключ из панели
2. **Проверьте баланс** - возможно баланс нулевой и запросы не проходят
3. **Задержка обновления** - статистика может обновляться с задержкой (до 5-10 минут)
4. **Другой аккаунт** - возможно API ключ от другого аккаунта

## 📝 Формат ответа API

CheckNumber.ai возвращает:
```json
{
  "status": "OK",
  "message": {
    "number": "+1234567890",
    "whatsapp": "yes"  // или "no", или "checking"
  },
  "pricingStrategy": "PAY",  // или "FREE"
  "transactionId": "unique_transaction_id"
}
```

## ⚠️ Важно

- **Все запросы платные** (кроме тестовых с `pricingStrategy: FREE`)
- **Пополните баланс** перед использованием в продакшене
- **Следите за балансом** - когда баланс закончится, API перестанет работать
- **TransactionID** - используйте его для отслеживания запросов в панели

## 🚀 Готово!

После настройки API ключа бот будет использовать только CheckNumber.ai для проверки WhatsApp. Все запросы будут учитываться в статистике и списываться с баланса.
