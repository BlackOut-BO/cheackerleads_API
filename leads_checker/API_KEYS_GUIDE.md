# Где найти API ключи для Checkerleads

## Abstract API (Email Validation)

**Важно:** API ключ находится НЕ в Account Settings!

### Где найти API ключ:

1. **Войдите в аккаунт** на https://app.abstractapi.com/
2. **Перейдите на Dashboard** (главная страница после входа)
3. **Найдите раздел "Email Validation API"** или перейдите по ссылке:
   - https://app.abstractapi.com/api/email-validation
4. **API ключ будет отображаться** на странице API или в разделе "API Keys"

### Альтернативные варианты:

Если вы не можете найти API ключ в Abstract API, можно использовать альтернативные сервисы:

#### Вариант 1: EmailJS (бесплатный)
- URL: https://www.emailjs.com/
- Простой в использовании

#### Вариант 2: Hunter.io Email Verifier
- URL: https://hunter.io/
- Хорошая точность проверки

#### Вариант 3: ZeroBounce
- URL: https://www.zerobounce.net/
- Профессиональный сервис

## ipdata.co (IP Checker)

1. Зарегистрируйтесь на https://ipdata.co/
2. Перейдите в Dashboard
3. API ключ будет в разделе "API Keys" или на главной странице

## numverify (Phone Validation)

1. Зарегистрируйтесь на https://apilayer.com/marketplace/numverify-api
2. Перейдите в Dashboard
3. API ключ будет в разделе "API Keys"

## RapidAPI

1. Зарегистрируйтесь на https://rapidapi.com/
2. Перейдите в Dashboard
3. API ключ находится в разделе "My Apps" → "Security" или в настройках профиля
4. Ключ называется "X-RapidAPI-Key"

## Если не можете найти API ключи

Если у вас проблемы с получением API ключей, можно:

1. **Временно отключить проверки** - бот будет работать, но без проверок
2. **Использовать альтернативные сервисы** - я могу помочь настроить другие API
3. **Тестировать без API** - парсер и бот будут работать, просто проверки вернут ошибки
