## 📋 Чек-лист перед запуском

1. **Установлены зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Создан файл .env:**
   ```bash
   cp env.example .env
   ```

3. **Заполнены API ключи в .env:**
   - TELEGRAM_BOT_TOKEN
   - ABSTRACT_API_KEY
   - IPDATA_API_KEY
   - NUMVERIFY_API_KEY
   - RAPIDAPI_KEY

4. **Проверена готовность:**
   ```bash
   python check_setup.py
   ```

5. **Запущен бот:**
   ```bash
   python main.py
   ```

## 🔧 Тестовые скрипты

- `test_imports.py` - проверка всех импортов
- `test_parser.py` - проверка парсера данных
- `check_setup.py` - полная проверка готовности

## ⚠️ Важные замечания

1. **API ключи обязательны** - без них проверки не будут работать
2. **Telegram токен обязателен** - без него бот не запустится
3. **Все проверки асинхронные** - для ускорения работы
4. **Обработка ошибок** - при отсутствии API ключей возвращаются ошибки, но бот продолжает работать
